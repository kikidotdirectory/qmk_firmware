# Boss Up

12u unibody split alphastag layout with exploded bars and pinky mods.

- Keyboard Maintainer: [Dashkeebs](https://dashkeebs.bigcartel.com/contact)

Make example for this keyboard (after setting up your build environment):

    qmk compile -kb dashkeebs/boss_up -kb default
 
To reset the keyboard, make sure it is plugged in, then simutaneously press and release the reset and boot buttons on the bottom of the PCB.

Install example for this keyboard:

    qmk flash -kb dashkeebs/boss_up -km default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
